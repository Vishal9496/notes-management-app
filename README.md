Notes Management Application
Tech Stack
Frontend: React + Vite
Backend: Spring Boot
Database: MySQL
Authentication: JWT
Build Tool: Maven
Project Structure
notes-management-app/ ├── notes-app └── notes_management_backend

Backend Setup
Open notes_management_backend
Configure MySQL in application.properties
Run: mvn spring-boot:run
Backend runs on: http://localhost:8080

Frontend Setup
Open notes-app
Run: npm install npm run dev
Frontend runs on: http://localhost:5173

Features
User Registration
User Login
User Logout
Create Notes
View Notes
Edit Notes
Delete Notes
JWT Authentication
User-specific Notes
Live URL
